# 🎮 Game Analytics Dashboard & Report

![Python](https://img.shields.io/badge/Python-3.11-blue?logo=python)
![Streamlit](https://img.shields.io/badge/Streamlit-App-red?logo=streamlit)
![Pandas](https://img.shields.io/badge/Pandas-Data%20Analysis-yellow?logo=pandas)
![Plotly](https://img.shields.io/badge/Plotly-Visualization-lightblue?logo=plotly)

Proyek ini merupakan bagian dari latihan **Data Analyst** yang mensimulasikan analisis perilaku pemain dalam sebuah game online.  
Analisis dilakukan menggunakan **Python, Pandas, Plotly**, dan **Streamlit**, kemudian hasilnya disajikan dalam bentuk **dashboard interaktif** serta **laporan PDF profesional**.

---

## 📊 Tujuan Proyek

Menganalisis perilaku pemain untuk menemukan insight seputar:
- Genre game dengan performa terbaik  
- Perangkat (device) yang paling aktif digunakan  
- Pola durasi bermain dan pembelian in-game  
- Rekomendasi bisnis berbasis data  

---

## 🧠 Tools & Teknologi
- **Python 3.11**
- **Pandas** — pembersihan & analisis data
- **Plotly** — visualisasi interaktif
- **Streamlit** — dashboard web
- **ReportLab** — pembuatan laporan PDF
